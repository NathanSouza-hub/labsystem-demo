# LabSystem - demo

Demo interativa do **LabSystem**, sistema de cadastro de produtos com autenticação.

**Ver a demo:** https://nathansouza-hub.github.io/labsystem-demo/ (login `demo` / `demo123`)

É o front-end original do projeto rodando sem servidor: o `demo-api.js` intercepta as chamadas à API e simula as mesmas rotas, validações e mensagens do back-end real (Node.js, Express, MySQL, JWT em cookie httpOnly e bcrypt). Os dados são de exemplo e ficam salvos só no navegador.

Código completo: https://github.com/NathanSouza-hub/labsystem
